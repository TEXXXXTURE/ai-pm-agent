# 分析报告模板

> 标题格式：《分析对象 + 时间范围》，例：《注册漏斗分析 2026-09-15 至 09-21》

## 1. 结论（三句话以内）

- 发生了什么：核心数字 + 与基线的差异。
- 影响多大：涉及多少用户、幅度多少。
- 建议做什么：一个或几个具体动作。

## 2. 口径与数据说明

- 指标怎么算的：引用计算口径，注明本次特殊设定（转化窗口、会话间隔等）。
- 数据范围：时间、平台、人群。
- 数据质量问题：缺失、重复、埋点故障；对结论的影响。没有问题写「未发现」。

## 3. 事实数据

按分析类型给出表格或数字：

- 漏斗：每步人数、逐步转化率、流失人数。
- 留存：同期群表（行为 D1/D7/D30）。
- 趋势：周期数值 + 环比/同比。
- 分群：各群人数与指标对比。
- 事件细分：各组数值与占比。

只放算出来的结果，此节不写推测。

## 4. 可能的原因

- 列出 2-3 个可能解释，每个标注依据（数据里看到了什么）。
- 区分「数据支持」与「猜测」。
- 无随机分流的发布分析，明确写「时间上相关，不能证明因果」，并列同期其他变化。

## 5. 建议动作

| 动作 | 解决什么 | 负责人 | 预期看哪个指标验证 |
|---|---|---|---|
| | | | |

没有明确建议就写「数据不足，建议先补某数据/观察一周」，不凑建议。
