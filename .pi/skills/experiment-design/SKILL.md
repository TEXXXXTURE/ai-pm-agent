# 实验设计技能（experiment-design）

设计一个**真能改变决策**的实验：可证伪的假设、跑得动的样本量、以及在数据到来**之前**就写死的发布/终止规则。实验不是"测了再说"——事后才找解释的实验，结果怎么都能讲圆，等于没做。

## 一、何时使用 / 先问用户什么

### 适用场景
- 用户说"帮我设计个 A/B 实验""这个改动想测一下效果""怎么验证这个想法值不值得做""这个实验结果算显著吗"。
- 手上有一个产品改动（新功能、文案、流程、定价页等），需要用数据决定上线、扩大还是砍掉。

### 不适用 / 先直说的情况
- **实验不支撑任何决策**：如果无论结果如何团队都会上线，明说"这个实验不该做"，改为上线后观测（post-launch measurement）——跑实验是有成本的。
- 流量/样本根本不够又无法接受替代方案时，不硬凑实验设计（见工作流第 4 步的替代方法）。

### 先问用户什么（最多 3 个问题，信息不足先澄清）
1. **这个实验支撑什么决策？**——什么结果上线、什么结果砍掉，决策人和决策时点是谁。没有决策门的实验不值得做。
2. **基线数据是多少？**——主指标当前值（如转化率 3.2%）和每周符合条件的流量（如每周 8000 个用户进入该流程）。没有这两个数，样本量无法算；用户没有时，引导其从分析工具取真实值，**不允许拍脑袋编**。
3. **最小可行动效应（MDE）是多少？**——"提升多少才值得行动"。"任何提升都行"不是答案：检测 0.1% 的提升可能需要的流量比整个产品的流量还大。MDE 由"多小的提升在业务上仍值得为之改动"决定。
4. （可并入第 1 问）**可承受的成本与周期**：能接受实验跑几周、多大比例用户进实验、有没有不能碰的红线（收入、合规、关键体验）。

规则：用户指令里已给出的信息直接采用、不重复问；**问题问完或用户不回应，带着【假设】标签继续，并在实验方案开头标注假设**；基线数据缺失时，方案中样本量部分给出公式和算法、数值处留空或标注【待填真实数据】，绝不编造。

## 二、工作流步骤

1. **把假设写成可证伪的形式**：
   "因为我们观察到 [证据]，我们相信对 [人群] 做 [改动]，会让 [主指标] 移动 ≥ [MDE]。
   如果出现 [可观测的反面结果]，我们就是错的。"
   假设必须引用促成它的证据（数据、用户反馈、调研），并写明"什么结果算我错"——不能证伪的假设无法被检验。
2. **只设一个主指标**。多个主指标等于变相 p-hacking（总有一个碰巧显著）。次要指标用于学习、不用于决策，并显式标注"仅学习用"。
3. **设护栏指标**：2–4 个**绝不能恶化**的指标（收入、延迟/性能、退订率、客服投诉量等），每个带容忍阈值（如"客诉量上升不超过 5%"）。
4. **样本量合理性检验**：
   - 用标准近似估算每组所需样本量（显著性水平 α=0.05、统计功效 power=0.8）。比率类指标的常用近似：每组 n ≈ 16 × p(1−p) / Δ²，其中 p 为基线比率、Δ 为要检测的绝对差值（例：p=0.03、Δ=0.005 时，每组约需 1.9 万）。需要精确值时用代码计算，不手算拍数。
   - 然后进行诚实对话：按当前流量，需要跑几周？**预计超过 8 周，就提出替代方案**：改动做大一点（效应更大）、放宽 MDE、换更敏感的代理指标（proxy metric）、或改用非实验方法——留出法（holdout）、带对照的前后对比、用户测试。
   - 把功效不足（underpowered）的实验仍然推荐去跑，是头号大忌——绝不沉默地放过。
5. **预先承诺决策规则**，四个分支全部在实验前写死：
   - 显著胜出（p<0.05 且达到 MDE）→ [动作，如全量上线]；
   - 显著变差 → [动作]；
   - 持平/无定论（跑满周期后）→ [动作——通常是砍掉，并明说]；
   - 护栏击穿（触及阈值）→ [停止规则与处置流程]。
   同时**预先固定实验时长**：不许偷看数据、趁某天好看就停；按完整周数跑，覆盖周内周期（工作日/周末差异）。
6. **明确分流与对照组**：对照/变体各是什么、分流比例、随机化单位（用户/会话/账户——单位选错会污染结论）、纳入人群与排除人群（及排除理由）。
7. **列出本设置下的有效性威胁**，每条带缓解措施或诚实声明：新奇效应（novelty effect）、季节性/节假日、组间污染（对照组能看到变体）、人群结构变化（segment mix shift）。
8. **风险与伦理边界**：实验不得伤害用户或剥夺用户已依赖的关键权益（对照组不应被拿掉已知必要的功能/安全能力）；涉及付费、隐私、敏感人群的改动谨慎评估并遵守数据合规要求；明确实验负责人（DRI）和一票停止的负责人；护栏击穿即停，不找补。

## 三、markdown 输出模板（实验方案）

```markdown
# 实验方案 — [实验名称]
**支撑的决策**：[什么结果决定什么上线/砍掉] · **DRI（负责人）**：[姓名]
**假设**：[用户未回答而采用的假设；没有则写"无"]

## 假设
因为 [证据]，我们相信对 [人群] 做 [改动]，会让 [指标] 移动 ≥ [MDE]%。
我们错了，如果：[可观测的反面结果]。

## 实验设计
分组：[对照组 / 变体组各是什么] · 分流：[各 %] · 随机化单位：[用户/会话/账户]
纳入人群：[谁符合条件] · 排除人群：[谁不进、为什么]
实验时长：[预先固定 N 周，起止日期] · 预先承诺：中途不偷看、不提前停

## 指标
**主指标（唯一，用于决策）**：[指标 + 精确定义，如"完成下单的用户占比 = 下单 UV / 进入结算页 UV"]
**护栏指标（不可恶化）**：[指标 · 容忍阈值] × 2–4 条
**次要指标（仅学习，不用于决策）**：[指标列表]

## 样本量与周期
基线：[X]% · MDE：[Y]%（相对/绝对，注明）· 每组所需 n：[计算值] · 按当前流量预计：[Z] 周
[若 >8 周：推荐的替代方案——更大改动 / 放宽 MDE / 代理指标 / holdout / 前后对比 / 用户测试]
[基线数据缺失时：给出计算公式，数值标【待填真实数据】]

## 决策规则（实验前预先承诺）
- 胜出（p<0.05 且 ≥MDE）：[动作]
- 变差：[动作]
- 跑满 [N] 周后持平/无定论：[动作，通常为砍掉]
- 护栏击穿（[阈值]）：立即停止，[处置流程与负责人]

## 有效性威胁与缓解
[威胁 → 缓解措施/诚实声明：新奇效应 / 季节性 / 组间污染 / 人群结构变化]

## 风险与伦理
[对用户的潜在影响、对照组权益、隐私合规、停止条件与一票停止负责人]
```

落盘建议：实验方案可保存为 `output/实验方案-<名称>-<日期>.md`。需要做成汇报材料/演示时，按项目规矩产出《演示需求交接单》，不自制 HTML/PPT。

## 四、呈现前质量自检清单

- [ ] **假设可证伪**，且引用了促成它的证据；"什么结果算错"是可观测的具体结果
- [ ] **主指标恰好一个**；次要指标显式标注"仅学习用"
- [ ] 护栏指标 2–4 个，每个都有量化容忍阈值和击穿后的停止流程
- [ ] **样本量是算出来的、不是断言的**——展示基线、MDE、n、周数的推导过程；用了真实基线数据，未编数字
- [ ] **周期是诚实的**：超过 8 周已提出替代方案；没有把功效不足的实验沉默地推荐出去
- [ ] **四个决策分支全部预先承诺**，包括令人不舒服的"持平 → 砍掉"分支；实验时长预先固定、写明不偷看
- [ ] 分流设计完整：分组、比例、随机化单位、纳入/排除人群
- [ ] 有效性威胁逐条列出且有缓解或声明；风险与伦理边界（用户权益、隐私合规、停止负责人）已写明
- [ ] 如果实验不支撑任何决策，已明确建议"不做实验、改为上线后观测"
- [ ] 产物为 markdown
