## 一、使用规则（给 Agent）

1. **先判形态**：用户要的是文档（PRD/报告/纪要 → Markdown，你自己做）还是**演示物**（PPT/网页幻灯片/数据图表/流程图/泳道图/思维导图/视频）？演示物不走 Markdown，走本表。
2. **先出交接单再动手**：演示需求先按 `demo-handover` 技能澄清五要素（演示什么/受众/核心结论/数据素材/期望形式），信息不全先问。
3. **查表定位**：按"期望形式"找到对应工具行，看**安装状态**：
   - **✅ 已装**：按"调用入口"加载技能、按技能指引制作；产物落 `output/`。
   - **⏳ 未装/待配环境**：明确告诉用户"该工具尚未就绪"，给出两个选择——**①用户自行提供工具**（放进外置包 skills/tools 并通知登记）；**②授权 Agent 下载本表已预筛选的工具**（说明来源、用途、安装方式，经用户同意后执行，装完更新本表状态）。
4. **不许假装能做**：没有对应工具时，不得硬用 Markdown 拼凑演示物，也不得编造工具调用结果；诚实说明能力边界（G8）。
5. **用完登记**：新装/更新工具后，更新本表与外置包 `工具包说明.md` 的状态。

## 三、外置包位置约定

- 根目录：`D:\Agent外置工具包\演示工具包\`
- `skills\`：技能文件夹（每个内含 SKILL.md；Pi 启动时经 `scripts/run-pi.ps1` 的 `--skill` 参数加载已装项）
- `tools\`：运行依赖（venv、node 环境等）
- 包内 `工具包说明.md`：装箱单（清单、来源、license、更新方式、用户自行添加工具的方法）
- 新增工具包（非演示类，如未来数据处理包）在 `D:\Agent外置工具包\` 下另建中文文件夹，并在本表增节登记。
