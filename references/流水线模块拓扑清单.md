# 流水线模块拓扑清单（画布地基）

> 用途：画布式需求表达（docs/画布式需求表达-设计共识.md）的第一步——把现有流水线 20 节点的拓扑、接口、依赖、对应源码摸清，供画布前端（人编辑）与 Agent（读图改代码）共用。
> 来源：`src/kernel/graph.py`（图定义）+ `src/nodes/`（节点实现）实读，2026-09-18。
> 约定：节点 = 图上一个单元；边 = 连线；条件边 = 按路由函数分流；END = 终态。
> 本清单是「画布 ↔ 源码」的对应索引：改某个模块时，从画布节点定位到源码文件。

## 二、拓扑（边 + 条件边）

线性边：
- kb_lookup → intake → requirement_confirm
- feasibility_check → feasibility_confirm
- prd_generation → prd_review
- eval_design → eval_confirm
- issue_splitting → issue_confirm
- eval_run → eval_gate
- launch_plan → readiness_assessment → launch_confirm

条件边（节点 → 路由函数 → 出口映射）：
- **requirement_confirm** → route_after_requirement_confirm → {needs_discovery, requirement_refine}
- **requirement_refine** → route_after_requirement_refine → {needs_discovery, requirement_refine(自环), END}
- **needs_discovery** → route_after_needs_discovery → {feasibility_check, prd_generation}（按 ai_core 分流）
- **feasibility_confirm** → route_after_feasibility_confirm → {prd_generation, requirement_confirm, END}
- **prd_review** → route_after_review → {prd_generation(打回), eval_design(AI轨), issue_splitting(普通轨)}
- **eval_confirm** → route_after_eval_confirm → {eval_design(改), bake_off(AI轨确认)}
- **bake_off** → route_after_bake_off → {issue_splitting, bake_off(自环)}
- **issue_confirm** → route_after_issue_confirm → {issue_splitting, prd_generation, launch_plan, eval_run}
- **eval_gate** → route_after_eval_gate → {launch_plan, eval_run(重跑)}
- **launch_confirm** → route_after_launch_confirm → {artifact_persist, launch_plan, issue_splitting}

## 四、停人点（8 个节点）

`requirement_confirm`（hitl.py）/ `requirement_refine`（refine.py）/ `feasibility_confirm`（feasibility.py）/ `eval_confirm`（eval_design.py）/ `bake_off`（bake_off.py）/ `issue_confirm`（issues.py）/ `eval_run`（eval_run.py）/ `launch_confirm`（launch_plan.py）——均 interrupt + SQLite 断点续跑，恢复用 `--resume <thread_id> --answer "..."`；各点答复协议见 `AGENTS.md` 同名小节。

## 五、与画布方案的对应

- 每个「节点」→ 画布一个模块块，暴露：输入接口（state 字段）、输出接口、可调参数（config/prompt/阈值）。
- 每条「边」→ 画布一条连线；条件边 → 画布标注路由条件（如「ai_core → AI 轨」）。
- Agent 读本清单（或画布导出的结构图 JSON）→ 定位 `src/nodes/<file>` → 改单个模块。
- 可调参数是「画布上能改的旋钮」——改阈值/prompt 走配置/提示词，不需要动代码结构。
