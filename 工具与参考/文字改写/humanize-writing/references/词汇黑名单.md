# 中文 AI 味词汇黑名单

> 整理自 [cn-humanizer](https://github.com/0xtresser/cn-humanizer)（词汇表主体）与 [stop-slop-zh](https://github.com/pencil20388-eng/stop-slop-zh)（补充）。 <!-- [MA 2026-09-12] -->

用法：一级词发现即删换；二级词单个出现正常，一段出现 3 个以上就要处理；套话短语直接删。

## 自造词与行话（AI 自己造的指代词，任何场合都要清）

这是 AI 味的头号来源，比"赋能""抓手"那类词更隐蔽：AI 写东西时习惯把一段事实压成一个名词，造出只有它自己用的"内部术语"，读者看到会以为自己漏了背景知识。

**判定三分法（不一刀切）**：

| 类型 | 处置 | 例子 |
|---|---|---|
| ① 领域原生术语（专业圈里一直有的词） | 可以用；读者可能不懂时，第一次出现补一句解释 | 合同、条款、违约金、召回率、误报率 |
| ② 团队/项目约定过的内部词 | 可以用；首次出现必须用一句普通话解释，之后才用简称 | 工单、确认点、发布计划 |
| ③ **AI 现场造出来做指代的词** | **不能用**；不是换近义词，而是把它指的事情本身写出来 | 见下表 |

判定第 ③ 类的两个问题：**这个词在读者那个圈子里以前出现过吗？读者第一次看到它，能不能猜出指什么？**只要有一样不成立，就是自造词。

| 自造词 | 改成（把事写出来） |
|---|---|
| 横跑 | 把同一批考题分别发给每个候选模型各跑一遍，比结果 |
| 体系门 / XX门 | 停下来等确认的地方 |
| 断点 | 跑到一半存下来的进度 |
| 骨架 / 归档 | 会话记录 / 写会话记录 |
| 探针 | 拿几个真实样例试跑模型，看它能不能做 |
| 落盘 | 写成文件保存到目录 |
| 双轨 / 纵切 | 两条路线 / 按"用户能做完一件事"切分工单 |
| 内循环 / 外置 | 反复要跑的步骤 / 放在项目外面，用到时才调 |
| 回炉 | 退回去重写 |
| 口径 | 判定标准 / 说法 |
| 载体 | 放在哪（哪个文件、哪个脚本） |

**为什么不能"统一成一个词反复用"**：自造词省的是写字人的力气，花的是读的人的力气。读者得先猜它指什么，再回到内容上——这是双重成本。

**自查**：把文中每个名词读一遍，问"第一次看到这个词的人能不能猜出它指什么"。猜不出就展开成一句话。

## 一级词（出现即可疑，必须换）

| 词 | 替代说法 |
|---|---|
| 赋能 | 帮、支持、给…用上 |
| 深耕 | 做了很久、专注于 |
| 聚焦 | 关注、主要做 |
| 助力 | 帮、推动 |
| 打造 | 做、建 |
| 引领 | 带头、领先 |
| 全方位 | 各方面（或直接说哪几方面） |
| 多维度 | 直接说哪几个维度 |
| 高质量 | 用数据说明质量 |
| 沉浸式 | 描述具体体验 |
| 一站式 | 全包、什么都有 |
| 闭环 | 从头到尾、形成循环 |
| 抓手 | 切入点、办法、工具 |
| 底层逻辑 | 根本原因、说白了 |
| 顶层设计 | 整体规划、大方向 |
| 降本增效 | 省钱、提效率 |
| 提质增效 | 做得更好更快 |
| 数智化 | 数字化、用上了 AI |
| 新质生产力 | 说具体是什么技术、什么产能 |

## 二级词（一段 3 个以上才处理）

| 词 | 替代说法 |
|---|---|
| 此外 | 还有、另外，或直接说下一句 |
| 值得注意的是 | 删掉，直接说 |
| 值得一提的是 | 删掉，直接说 |
| 毫无疑问 | 确实、没错 |
| 不言而喻 | 明摆着 |
| 众所周知 | 大家都知道，或删掉 |
| 不可否认 | 确实 |
| 与此同时 | 同时、而且 |
| 事实上 | 其实 |
| 总的来说 | 删掉或直接说结论 |
| 综上所述 | 删掉 |
| 由此可见 | 所以 |
| 不难发现 | 删掉，直接说发现了什么 |
| 至关重要 | 直接说为什么重要 |

## 宣传腔（换事实）

亮眼、瞩目、欣欣向荣、蓬勃发展、硕果累累、令人振奋、可圈可点、有目共睹、蒸蒸日上、日新月异、突飞猛进、如火如荼、方兴未艾、势不可挡。

改法：删掉形容词，补一个数字或事实。

## 意义拔高短语（换成事情本身）

- "具有里程碑式的意义" — 删，说做了什么
- "标志着…的新篇章" — 删
- "开创了…的先河" — 删
- "翻开了…的新一页" — 删
- "谱写了…的新华章" — 删
- "为…注入了新的活力" — 说清注入了什么
- "为…奠定了坚实基础" — 说清做了什么、效果是什么
- "树立了…的新标杆" — 删

## 万能开头（删掉直接进入正题）

"随着…的不断发展"、"在当今…的时代"、"在…的背景下"、"作为…的重要组成部分"、"从…的角度来看"、"众所周知"、"毋庸置疑"。

## 万能结尾（删掉，说完就停）

"让我们拭目以待"、"未来可期"、"前景广阔"、"大有可为"、"值得期待"、"充满无限可能"、"我们有理由相信"、"相信在未来"、"站在新的起点上"。

## 客服腔（对话场景删换）

"以下是关于…的介绍"、"针对您的问题"、"根据您的需求"、"希望以上信息对您有所帮助"、"如有疑问请随时咨询"、"非常感谢您的提问"、"以上供参考"、"仅供参考"、"不当之处敬请指正"、"水平有限"。

改法：直接给答案和结果；结尾说清做到了哪、需要对方给什么。
