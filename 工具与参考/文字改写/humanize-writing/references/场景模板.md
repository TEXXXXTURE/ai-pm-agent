# 场景模板

> 改写自 Structured Brief（[LuD1161](https://gist.github.com/LuD1161/084ba8cea409384c4269dbee9359f002)）。结构乱时按场景套用。 <!-- [MA 2026-09-12] -->

用法：先判断这段文字在干什么（汇报、交接、对比、调查、解释），套对应骨架重排。骨架里没有的内容删掉，有的内容缺了标"待补"，不编造。

## 汇报做完的事

```
做了什么：一句话说结果（做完/没做完/做到哪）
证据：关键数字、产出文件、验证结果
问题：遇到什么没解决的（没有就写"无"）
下一步：下一个动作是什么，需要对方给什么
```

## 交接工作

```
目标：这件事要达成什么（一两句）
现状：已完成 / 进行中（写到哪，文件路径）/ 未开始
下一步的第一个动作：具体做什么
注意：踩过的坑、别动的地方
```

## 方案对比（A 还是 B）

```
问题：要解决什么
两个方案各自怎么做、代价是什么（各三句内）
建议：选哪个，为什么（一句话）
待定项：需要对方拍板什么
```

## 调查结论

```
事实：查到了什么（带来源）
结论：所以判断是什么
没查到的：哪些说法没有来源、标了未核实
```

## 解释一个东西（用户问"什么是/怎么理解"）

```
一句话定义：它是什么
它解决什么问题：没有它会怎样
怎么用：一个具体用法或场景
```
